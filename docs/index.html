uvm

UV 镜像源管理工具 - 一键管理 uv 的 PyPI 镜像源

$ pip install ouvm

功能特性

快速切换

一键切换国内外 PyPI 镜像源，告别手动编辑配置文件

速度测试

自动测试镜像源响应时间并排序，推荐最快镜像源

自定义源

支持添加公司/学校内部镜像源，灵活管理

跨平台

完美支持 Windows、macOS、Linux 系统

常用命令

命令短命令说明
uvm listuvm ls列出所有镜像源
uvm use tsinghuauvm u tsinghua切换到清华源
uvm testuvm t测速并排序
uvm currentuvm cur查看当前镜像源
uvm resetuvm r恢复官方源
uvm add <name> <url>uvm a添加自定义镜像源
uvm remove <name>uvm rm删除自定义镜像源
uvm search <query>uvm s搜索镜像源
